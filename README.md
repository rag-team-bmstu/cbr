# Система поиска информации в нормативных документах финансовой сферы

## О проекте

Проект представляет собой систему поиска информации в нормативных и справочных документах финансовой сферы.

Основной пользователь системы — сотрудник банка, финтех-компании или другой специалист, которому необходимо быстро найти нормативную информацию по конкретному вопросу, но при этом может быть неизвестно точное название или номер документа.

Пользователь формулирует вопрос на естественном языке, после чего система находит наиболее релевантные документы и фрагменты.

В итоговой версии проекта найденные материалы также будут использоваться для формирования краткого ответа пользователю с указанием источников.

Пример запроса:

> В каких случаях банк может отказать клиенту в проведении операции?

---

## Основной пользовательский сценарий

1. Пользователь открывает приложение.
2. Вводит вопрос в поисковую строку.
3. Система выполняет поиск по корпусу документов.
4. Пользователь получает наиболее релевантные результаты.
5. Для каждого результата отображаются документ, его источник и релевантный фрагмент.
6. Пользователь может открыть подробную информацию об источнике.
7. В итоговой версии система также формирует краткий ответ на основе найденных материалов.

## Запуск frontend-прототипа

Для запуска требуется Python.

Перейдите в каталог frontend:

```bash
cd frontend
```

Запустите локальный HTTP-сервер:

```bash
python -m http.server 8000
```

После запуска откройте в браузере:

```text
http://localhost:8000
```

Остановить сервер можно сочетанием:

```text
Ctrl + C
```

## Проверка основных состояний

### Успешный поиск

Например:

```text
В каких случаях банк может отказать клиенту в проведении операции?
```

После отправки запроса отображаются состояние загрузки, демонстрационный ответ и найденные документы.

### Пустой запрос

Если нажать кнопку `Найти`, не вводя текст, система сообщит:

```text
Введите вопрос для поиска.
```

### Отсутствие результатов

Для демонстрации этого состояния можно использовать запрос:

```text
Квантовые технологии в банковском регулировании
```

Система отобразит сообщение:

```text
По вашему запросу ничего не найдено.
Попробуйте изменить формулировку.
```

### Просмотр источника

В результатах поиска необходимо нажать:

```text
Открыть источник
```

Справа откроется панель с информацией о документе и найденном фрагменте.
