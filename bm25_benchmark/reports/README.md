# Результаты бенчмарка

Прогон от 20 ноября 2026 года выполнен на едином корпусе версии 1.6 с 4 097 документами и разделами и 166 523 фрагментами. Демо, CLI и бенчмарк используют файл `data/corpus.jsonl.gz`. Прогон обеих выборок с двумя токенизациями занял 1 минуту 45 секунд. [Команда для повторного прогона](../README.md#бенчмарк)

| Выборка | Вопросы | Токенизация | Recall@3 | MRR@3 | Без совпадений с разметкой |
| --- | ---: | --- | ---: | ---: | ---: |
| Отладочная | 3 | Базовый BM25 | 0,4444 | 0,5000 | 1 |
| Контрольная | 15 | Базовый BM25 | 0,4011 | 0,7000 | 4 |
| Отладочная | 3 | BM25 со Snowball | 0,7778 | 1,0000 | 0 |
| Контрольная | 15 | BM25 со Snowball | 0,5244 | 0,7667 | 1 |

В контрольной выборке Snowball нашёл хотя бы один эталонный источник для 14 из 15 вопросов. По вопросу `t13` все три эталонные публикации о приостановке перевода попали в первые три результата. По вопросу `t01` о сроке ответа МФО ни один из шести эталонных источников туда не попал. [Выдача по вопросам](bm25-at-3.json)

В обоих режимах использованы те же вопросы и разметка, параметры BM25 с k₁ = 1,2 и b = 0,75 и глубина выдачи в три разные публикации. Участник проекта подтвердил 56 связей для 15 контрольных вопросов 20 ноября 2026 года. Метрики измеряют попадания по этим связям. Архивные сценарии проверяются отдельно по реквизитам и страницам оригиналов. [Лист проверки](../docs/relevance-review.md)

JSON-отчёт содержит выдачу по каждому вопросу, параметры и SHA-256 файла, по которому выполнен прогон. [Полный отчёт](bm25-at-3.json)
