# Проверка разметки человеком

20 ноября 2026 года участник проекта подтвердил разметку контрольного набора. Это вопросы [t01–t15](#t01--test) и 56 связей с источниками. Вопросы d01–d03 используются для отладки.

1. Прочитайте вопрос и обоснование под ним. Откройте источник и найдите фрагмент, который подтверждает обоснование.
2. Отметьте `[x]`, если источник содержит прямой ответ, существенное условие или исключение, нужное для ответа. Совпадения темы для отметки недостаточно.
3. Для ошибочной связи запишите ID вопроса, ID документа и замечание. Для пропущенного источника запишите ID вопроса и ссылку.

После проверки всех контрольных связей сообщите, какие подтверждены и какие требуют исправления. Подтверждение записывается в `data/dataset.json`. Если разметка изменится, отчёт пересчитывается.

## Повторная проверка ИИ

19 ноября 2026 года сверены 56 связей для 15 контрольных вопросов по 24 публикациям Банка России. Критерий релевантности — прямой ответ либо существенная часть ответа, условие или исключение. По этому критерию у каждого контрольного вопроса подтверждены минимум три источника. В пунктах `t02`, `t11` и `t14` уточнены границы того, что подтверждают отдельные публикации. В `t15` в вопрос добавлено условие о той же сумме перевода, указанное в FAQ.
