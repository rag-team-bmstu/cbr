# Поиск по финансовым документам

Часть проекта НИРС «Разработка RAG-системы поиска и формирования ответов по нормативно-справочной документации финансового рынка». Поиск работает по российским законам, разъяснениям и официальным публикациям Банка России.

## Что можно запустить

- **RAG-демо в браузере.** Введите вопрос на русском. BM25 найдёт фрагменты, а DeepSeek через Coarena соберёт из них ответ. Ссылки под ответом ведут к фрагментам и документам.
- **Поиск из терминала.** Запрос возвращает документы, содержимое лучших фрагментов и их баллы BM25 в JSON.
- **Бенчмарк для контрольной точки.** Команда запускает поиск по размеченным вопросам, считает метрики и сохраняет выдачу по каждому запросу.

## Установка

Требуется Python 3.10 или новее. Выполните из корня репозитория.

```bash
cd bm25_benchmark
python3 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements.txt
```

Готовый корпус входит в проект. Все команды ниже запускаются из каталога `bm25_benchmark`.

## Демо

Создайте `.env` по [шаблону](.env.example) и впишите ключ Coarena в `COARENA_API_KEY`. Для генерации используется бесплатный план Coarena.

```bash
.venv/bin/python -m demo
```

Когда сервер напечатает адрес, откройте демо и введите вопрос. Под ответом показаны подтверждающие фрагменты. Ссылки в ответе и карточках ведут к оригиналам. Если материалов недостаточно, демо сообщает об этом. Сервер останавливается сочетанием `Ctrl+C`. [Открыть демо](http://127.0.0.1:8765/)

Для проверки поиска без генерации выполните запрос по реквизитам акта.

```bash
.venv/bin/python -m cbr_bm25 search 'Первоначальная публикация Положения Банка России № 762-П' --top-k 1
```

В выдаче будет официальная публикация с датой и ссылкой на страницу PDF. Этот запрос проверяет поиск исходного текста по реквизитам.

## Бенчмарк

Для прогона в рантайме на контрольной точке выполните команду. Она работает локально и не требует ключа Coarena.

```bash
.venv/bin/python -m cbr_bm25 benchmark --split all --tokenizer both --top-k 3 \
  --output /tmp/cbr-benchmark.json
```

В терминале появятся четыре строки для двух выборок (`dev` и `test`) и двух вариантов токенизации. Snowball приводит разные формы русских слов к общей основе, например «банки» и «банков» к `банк`.

- **Recall@3** показывает, какая доля эталонных публикаций попала в первые три результата. Если из четырёх эталонных источников найдено два, для этого вопроса метрика равна 0,5.
- **MRR@3** усредняет обратный ранг первого попадания. Первый эталонный источник на втором месте даёт вклад 0,5. При отсутствии попаданий вклад равен нулю.

В JSON-отчёте есть первые три результата каждого запроса, пропущенные эталонные ID, параметры и SHA-256 корпуса. Оценка относится к поиску по 18 размеченным вопросам, из которых 15 контрольных. Результаты генерации проверяются в демо. [Результаты прогона](reports/README.md)

Тесты проверяют формулу BM25, выбор источников, подсчёт метрик и обработку цитат.

```bash
.venv/bin/python -m unittest discover -s tests
```

## Единый корпус

Демо, поиск из терминала и бенчмарк используют один файл. Снимок источников от 19 ноября 2026 года содержит 4 097 документов и разделов и 166 523 фрагмента. Готовый файл занимает 70,5 МиБ. [Снимок корпуса](data/corpus.jsonl.gz)

| Материалы в корпусе | Документы и разделы |
| --- | ---: |
| Действующие на дату снимка редакции федеральных законов и кодексов из ЭБПИ | 1 288 |
| Разъяснения, справочные материалы и датированные показатели | 250 |
| Официальные публикации из реестра Банка России за 2016–2026 годы | 2 559 |

В архивных результатах указаны дата публикации и страница оригинала. Для вопросов о действующем правиле демо опирается на редакцию с подтверждённой датой действия или применимое разъяснение. Состав источников и подготовка снимка описаны в техдокументации. [Реестр официальных публикаций](https://www.cbr.ru/analytics/na_vr/) · [Техническая документация](docs/technical.md)
