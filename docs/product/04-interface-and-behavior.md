# 04. Интерфейс и поведение

На текущем этапе функции представлены в виде frontend-прототипа на демонстрационных данных. Описание будущего продукта не означает наличия серверной реализации.


## Назначение документа

Документ описывает основные элементы пользовательского интерфейса и поведение системы при взаимодействии с пользователем.

Интерфейс должен поддерживать основной сценарий:

ввод запроса → запуск поиска → просмотр результатов → просмотр источника.

---

## 1. Главная страница

Главная страница является основной точкой взаимодействия пользователя с системой.

На начальном экране отображаются:

- основной заголовок «Найдите нужный документ»;
- поясняющий текст «Задай вопрос»;
- поле для ввода поискового запроса;
- кнопка «Найти»;
- примеры возможных запросов;
- декоративная иллюстрация.

Пример поискового запроса:

> В каких случаях банк может отказать клиенту в проведении операции?

### Поведение

Пользователь вводит вопрос в поисковое поле и запускает поиск.

Запустить поиск можно:

- нажатием кнопки поиска;
- при необходимости — клавишей Enter.

Если поле запроса пустое, поиск не выполняется.

---

## 2. Состояние выполнения поиска

После отправки корректного запроса система начинает поиск по корпусу документов.

Во время выполнения поиска пользователь должен понимать, что запрос обрабатывается.

Интерфейс может отображать:

- индикатор загрузки;
- текстовое сообщение о выполнении поиска.

После завершения поиска состояние загрузки исчезает и отображаются результаты.

---

## 3. Результаты поиска

Результаты отображаются на той же странице под поисковой строкой.

Результаты должны быть расположены в порядке релевантности запросу.

Для каждого найденного материала отображаются:

- название документа;
- релевантный фрагмент текста;
- информация об источнике;
- элемент для просмотра источника или подробной информации.

Пример структуры результата:

```text
Название документа

Фрагмент текста, содержащий информацию,
относящуюся к запросу пользователя.

Источник: ...

[Подробнее]

```


## Расширенная структура интерфейса

Header: компактная существующая иллюстрация как кнопка возврата на начальный поиск; разделы Поиск, Каталог, История; Войти либо имя с меню История / Выйти.

Поиск сохраняет текущую композицию, примеры и PNG. Пустой запрос показывает валидацию. Загрузка сменяется mock-ответом или пустой выдачей. Запрос «Квантовые технологии» показывает отсутствие результатов. Источники ответа перечислены обычным текстом, без кнопок 1/2.

Каталог использует общие карточки документов и совместные фильтры по названию/номеру, статусу и типу. Пустая выдача предлагает сбросить фильтры.

История гостя приглашает войти. Для вошедшего пользователя отображаются запросы этой сессии с временем и количеством документов; при отсутствии записей доступен переход к поиску.

Drawer без декоративного изображения показывает реквизиты, статус, даты, фрагмент и связанные документы. При переходах по связям доступна кнопка Назад. Escape и overlay закрывают drawer, фокус возвращается к вызвавшей кнопке.

Формы входа/регистрации открываются в компактном modal, закрываются кнопкой или Escape. После успешного mock-входа обновляется header.

Загрузка: системный выбор файла или drop → карточка имени и размера → Анализировать / Удалить. Далее «Распознаём документ...» → «Ищем похожие документы...» → демонстрационный результат с похожим документом, фрагментом и связями. Для имени с error — ошибка и кнопка повторной загрузки. Файл не отправляется и не анализируется.
